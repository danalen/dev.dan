Dashboard Financeiro

Interface interativa para controle de gastos corporativos com gráficos dinâmicos e exportação de relatórios.

O Desafio

O cliente necessitava de uma interface mais moderna e reativa para acompanhamento de KPIs financeiros, pois o sistema legado gerava apenas tabelas estáticas sem possibilidade de análise gráfica interativa e cruzamento de dados em tempo real.

A Solução Técnica

Desenvolvi um dashboard frontend utilizando React para garantir atualização de estado e reatividade. Criei componentes gráficos utilizando bibliotecas modernas e estilizei toda a interface com Tailwind CSS para garantir responsividade e um visual clean e focado na usabilidade.

Resultados

O novo dashboard permitiu aos analistas financeiros cruzar informações de diferentes fontes na mesma tela e exportar relatórios customizados, reduzindo significativamente o tempo de análise diária.
